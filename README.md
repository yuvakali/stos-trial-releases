# STOS Trial

SpaceTug Orbital Simulator — Trial Edition. Ready-to-run installers, no prerequisites required.

## Download v1.0.1

| Platform | Installer | Notes |
|----------|-----------|-------|
| Windows  | `STOS-Trial-Setup-1.0.1.exe` | Installer (NSIS). Also `STOS-Trial-1.0.1-Portable.exe` for no-install use. |
| Linux    | `STOS-Trial-1.0.1-x86_64.AppImage` / `stos-trial_1.0.1_amd64.deb` | AppImage: `chmod +x` then run. DEB: `sudo apt install ./stos-trial_1.0.1_amd64.deb`. |
| macOS    | `STOS-Trial-1.0.1-arm64.dmg` | Apple Silicon. |

## Install notes

- **Windows:** SmartScreen may warn about the unsigned installer. Click *More info* then *Run anyway*.
- **macOS:** Gatekeeper will block unsigned apps. Right-click the app (or DMG) and choose *Open*, then *Open* again.
- **Linux:** AppImage may need `chmod +x`; DEB requires no special handling.

Fully offline — no internet or dependencies required after install.
